This project predicts customer churn using machine learning. By analyzing data like demographics, account info, and service usage, models like Random Forest and Logistic Regression were built. The goal is to help businesses identify at-risk customers and implement retention strategies, reducing customer loss and improving satisfaction.
Customer churn refers to the phenomenon where customers stop doing business with a company or discontinue a service. In industries with intense competition, predicting churn is crucial, as retaining existing customers is more cost-effective than acquiring new ones. This project focuses on using machine learning techniques to predict which customers are likely to churn based on historical data, helping businesses take proactive measures to retain valuable customers.

The objective of the project is to build a predictive model that identifies customers who are at risk of leaving the company. By identifying churn patterns in customer behavior, businesses can tailor retention strategies that improve customer satisfaction, enhance loyalty, and ultimately reduce revenue loss. The dataset used in this project includes demographic details, account information, and service usage patterns of customers. Key features include demographic information such as age, gender, and senior citizen status; account details such as tenure, contract type, and payment method; and service usage details such as internet service, streaming, and phone service. The target variable in this dataset is customer churn, labeled as either "Yes" or "No."

The project involves several key stages, starting with exploratory data analysis (EDA), where patterns and relationships between features and churn are visualized. The data is then preprocessed to handle missing values, encode categorical variables, and scale numerical features. Several machine learning models, including Logistic Regression, Decision Tree, Random Forest, and Support Vector Machine (SVM), are trained on the data. Techniques like SMOTE are used to address class imbalance, ensuring the models are robust. Model evaluation is done using performance metrics such as accuracy, precision, recall, F1-score, and ROC-AUC. Among the models tested, Random Forest and Logistic Regression showed strong performance, especially in terms of recall.

The results of the project demonstrate the effectiveness of machine learning in predicting customer churn. The Random Forest model, in particular, achieved the highest accuracy and recall, successfully identifying high-risk customers. This project highlights the importance of leveraging data and machine learning to proactively manage customer retention. Future work could explore integrating additional customer interaction data and testing advanced models like XGBoost.
